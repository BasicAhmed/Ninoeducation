# Nino Education — Web Platform

Aviation education platform for Nino Education, helping Arab and Indian
students find, compare, and apply to flight schools in South Africa.

## Stack
- Next.js 16 (App Router) + TypeScript
- Tailwind CSS v4
- Brand tokens: `#fe5200` (Nino Orange), `#0b0d0f` (ink), `#f6f4f1` (cream), white
- Fraunces (display) + Inter (body) — IBM Plex Sans Arabic planned for `/ar`

## Status
Initial scaffold + homepage design direction. Not yet built: flight school
directory, filters/comparison, application system, accommodation directory,
cost calculator, "Find My School" quiz, admin dashboard, Arabic RTL locale.

## Local dev
```
npm install
npm run dev
```
